Sales

Sales Performance Evaluation Agent

I single-handedly built this multi-step, agentic workflow using my own product, Albato, and Claude Code.

It pulls call transcripts, analyzes and scores account executives' performance through a complex, multi-layered scoring model. An LLM judge verifies the output, and the final evaluation gets posted to Slack, giving the AE valuable coaching tips. A deal action plan is then created and synced to HubSpot to help the AE navigate the deal after the sales call.

  1. 01 Pulls call transcripts
  2. 02 Scores AE performance with a multi-layered model
  3. 03 LLM judge verifies the output
  4. 04 Posts evaluation and coaching tips to Slack
  5. 05 Creates a deal action plan and syncs it to HubSpot
